# Tea Garden Landing Page

A simple, responsive landing page for a tea shop that showcases its unique blends and welcoming atmosphere. It was developed as a laboratory work for the Web Programming course at TUM.

## Overview

Tea Garden is a fictional tea shop specializing in high-quality, ethically sourced teas from around the world. This landing page was designed to provide customers with an elegant and intuitive browsing experience while highlighting the shop's key offerings.

## Features

- **Responsive Design**: Fully optimized for all device sizes (mobile, tablet, desktop)
- **Interactive Elements**: Hover effects on items and navigation
- **Embedded Google Maps**: Integrated location map in the contact section
- **Smooth Navigation**: Quick access to all sections via the fixed navigation bar
- **Call-to-Action**: Strategically placed order buttons throughout the page

## Development

This project was built using vanilla HTML and CSS without any frameworks. The design focuses on creating an elegant and intuitive user experience that reflects the calming and sophisticated nature of the tea shop.

### Color Palette

- Primary Purple: #774C60
- Cream Background: #F8EBDE
- Light Mauve Accent: #D8C4BF
- Dark Green Text: #15291B

## Deployment

This site is hosted on Netlify with continuous deployment from the GitHub repository. You can visit it at: https://tea-garden.netlify.app
